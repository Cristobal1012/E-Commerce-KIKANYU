# UI moderna y móvil

- Diseña y prueba primero a 375px; luego escala a escritorio.
- Estética limpia y premium: mucho aire, imagen protagonista, jerarquía tipográfica clara, pocos colores.
- Tamaños táctiles cómodos, foco visible, buen contraste, navegación por teclado, `alt` en imágenes.
- Imágenes optimizadas y con carga diferida; evita saltos de layout.
- Diseña estados vacíos, de carga y de error con la misma calidad que el estado ideal.
- Filtros y búsqueda reflejados en la URL para poder compartir.
- Reutiliza componentes y tokens existentes antes de crear nuevos.
- Meta de rendimiento: Lighthouse móvil sobre 90.
